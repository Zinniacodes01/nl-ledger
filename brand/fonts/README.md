# Brand font

**Archivo** (variable, weight 100–900, width 62–125), SIL Open Font License 1.1.

- Source: Google Fonts / Omnibus-Type. The site's own copy is `site/static/fonts/archivo-roman.woff2`; this is the same file.
- The wordmark is Archivo at weight 900, width 64, spaced by hand and outlined (`brand/src/wordmark.py`). It needs no font at run time.
